# FuelLoc 1.0.2

This maintenance release fixes device-state synchronization and recovery after intermittent USB disconnections.

## Fixed

- Fixed the device list and connection indicator remaining stale after the phone disconnected. They now synchronize automatically every five seconds.
- Fixed reconnecting the same phone reusing a closed tunnel, which could make **Simulate Location** fail with `userspace dial plane is closed`.
- Fixed incomplete resource cleanup after failed or timed-out device operations. **Disconnect** now closes the backend tunnel as well as updating the interface.
- Fixed **Stop Location** reporting success without sending a restoration command when no location service remained after reconnecting. It now opens a fresh service when needed.

## Download and update

Download **[FuelLoc-1.0.2-windows-x64.zip](https://github.com/sunheat/FuelLoc/releases/download/fuelloc-v1.0.2/FuelLoc-1.0.2-windows-x64.zip)**, extract the entire ZIP, and run **FuelLoc/FuelLoc.exe**. Keep the `_internal` folder beside the executable. Python is not required. The executable is unsigned and may trigger a Windows reputation warning.

To upgrade, choose **Stop Location**, **Disconnect**, and **Exit** in the existing app, then extract the new release into a separate folder. Saved places and preferences remain in `%LOCALAPPDATA%\FuelLoc` and are preserved.

Also included: **FuelLoc-1.0.2-source.zip** with matching source and build instructions, and **SHA256SUMS.txt** with archive checksums.

## Compatibility and usage

Use Windows x64, Edge or Chrome, Apple Mobile Device Support, and a trusted USB-connected iPhone with Developer Mode enabled. See the [setup guide](https://github.com/sunheat/FuelLoc/blob/fuelloc-v1.0.2/docs/APPLE_DEVICE_SETUP.md).

After reconnecting a phone, choose **Connect Device**, then retry **Simulate Location** or **Stop Location**. Simulation does not resume automatically. A broken physical connection can still prevent location restoration; check the phone's map after reconnecting.

FuelLoc is derived from GeoPort by davesc63 and distributed under GPLv3. See the [user guide](https://github.com/sunheat/FuelLoc#readme) for setup, network use, and troubleshooting.
