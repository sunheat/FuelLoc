# FuelLoc 1.0.1

This maintenance release fixes consecutive location changes. You can select a new point and simulate it without pressing **Stop Location** first.

## Fixed

- Fixed an issue where a second location change could report success while the phone remained at the previous location. FuelLoc now restores the previous simulation and renews the location session before applying the new point.
- Location changes and restoration now run sequentially, preventing overlapping requests from interfering with the active session.
- Replacing a location shows one result dialog. If restoration or setting fails, FuelLoc reports the error and does not add a successful location-history entry.

## Download and update

Download **[FuelLoc-1.0.1-windows-x64.zip](https://github.com/sunheat/FuelLoc/releases/download/fuelloc-v1.0.1/FuelLoc-1.0.1-windows-x64.zip)**, extract the entire ZIP, and run **FuelLoc/FuelLoc.exe**. Keep the `_internal` folder beside the executable. Python is not required. The executable is unsigned and may trigger a Windows reputation warning.

To upgrade, choose **Stop Location**, **Disconnect**, and **Exit** in the existing app, then extract the new release into a separate folder. Saved places and preferences remain in `%LOCALAPPDATA%\FuelLoc` and are preserved.

Also included: **FuelLoc-1.0.1-source.zip** with matching source and build instructions, and **SHA256SUMS.txt** with archive checksums.

## Compatibility and usage

- Windows x64, Edge or Chrome, Apple Mobile Device Support, and a trusted USB-connected iPhone with Developer Mode enabled. See the [setup guide](https://github.com/sunheat/FuelLoc/blob/fuelloc-v1.0.1/docs/APPLE_DEVICE_SETUP.md).
- The connection targets iOS 17 and later. Location changes and restoration have been verified on an iPhone 12 Pro Max running iOS 18.7.7.
- The phone may briefly use its real location when replacing a simulation. If Apple Maps remains centered on the previous point, tap its current-location button to recenter.
- Choose **Stop Location**, **Disconnect**, and **Exit** when finished. Closing the browser window alone leaves the controller running.

FuelLoc is derived from GeoPort by davesc63 and distributed under GPLv3. See the [user guide](https://github.com/sunheat/FuelLoc#readme) for setup, network use, and troubleshooting.
