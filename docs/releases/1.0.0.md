# FuelLoc 1.0.0

The first FuelLoc release brings iPhone location controls and reported Australian fuel prices into a portable Windows workspace. FuelLoc is derived from GeoPort by davesc63 and remains GPLv3 software.

## Download

Download **FuelLoc-1.0.0-windows-x64.zip**, extract it completely, and run **FuelLoc/FuelLoc.exe**. Keep `_internal` beside the executable. No Python installation is needed. The EXE is unsigned and may trigger a Windows reputation warning.

Also provided: **FuelLoc-1.0.0-source.zip** (matching source and build instructions) and **SHA256SUMS.txt** (archive checksums). GitHub's automatic source downloads do not contain the Windows app.

## Included

- USB device connection, location preview, simulation, and restoration using an in-process userspace tunnel without FuelLoc requesting administrator elevation.
- An Edge/Chrome app window, startup prerequisite checks, dark/light themes, and a map beside the controls.
- Address and coordinate search, draggable pins, Ctrl + scroll zoom, and optional additional map tools.
- Reported fuel prices with region/type filters and a five-minute cache lifetime; the next request refreshes expired data.
- Remembered local preferences and up to 30 saved places/recent locations, with named places protected from automatic replacement.
- Connection notifications, location-result dialogs, recovery hints, and optional Ko-fi support links.
- Loopback-only control server, cross-origin write checks, coordinate validation, and removal of the original device telemetry and remote broadcasts.

## Before using

Use Windows x64 with Edge or Chrome, Apple Mobile Device Support (included with iTunes), and a trusted, unlocked USB-connected iPhone with Developer Mode enabled. Internet access is needed for maps, search, prices, and any required developer-image download. Read the [setup and usage guide](https://github.com/sunheat/FuelLoc#readme).

Choose **Stop Location**, then **Disconnect** and **Exit** when finished. Closing the browser window alone leaves the controller running. If restoration fails, reconnect and retry Stop Location.

## Compatibility and limits

- Built and tested on Windows 11 x64. The current device path targets iOS 17+; an iPhone on iOS 18.7.7 has passed connection/disconnection and a short set/clear command check. The phone's displayed location was not independently verified. This is a limited compatibility check, not a guarantee for every iPhone or app.
- Older iOS, iPads, Wi-Fi device connections, Windows ARM64, macOS, and Linux are not verified release targets. This release provides Windows x64 binaries only.
- Fuel coverage and reporting delays depend on the external feed. Prices do not refresh in place automatically and should be confirmed with the station.
- Map/search/routing and interface resources require external services. See the [security review](https://github.com/sunheat/FuelLoc/blob/main/SECURITY_AUDIT.md) for network use and review limits.
- Saved places and preferences remain under `%LOCALAPPDATA%\FuelLoc`; replacing the portable folder preserves them.
